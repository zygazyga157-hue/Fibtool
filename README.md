# Fibtool Bots

This workspace contains:
- fib_square_strategy.py — Fibonacci + Square of Nine analysis
- degreefactor.py — DegreeFactor indicator
- supertrend.py — SuperTrend indicator
- utbot.py — UTBot indicator
- mt5_bg_collector.py — Background collector for XAUUSD
- entry_bot.py — Offline entry detector combining SuperTrend + UTBot and using S9 for TP/SL
- live_entry_bot_mt5.py — Live MT5 trader that places orders on ST+UT alignment with S9 TP/SL

## Entry Bot
Detect entries where SuperTrend and UTBot agree, and derive TP/SL from strong confluence zones (fallback to pivots).

### Quick start
1. Ensure you have bars saved at `outputs/xauusd_bars.csv` (generated by `mt5_bg_collector.py`).
2. Install Python deps (pandas, numpy).
3. Run the bot in dry-run to see how many entries it finds:

```powershell
python entry_bot.py --dry-run
```

4. Save entries to `outputs/entries.csv`:

```powershell
python entry_bot.py
```

### Options
- `--bars` path to OHLCV CSV (default: outputs/xauusd_bars.csv)
- `--symbol` label for entries (default: XAUUSD)
- `--timeframe` label (default: H1)
- `--st-period` SuperTrend period (default: 10)
- `--st-multiplier` SuperTrend ATR multiplier (default: 3.0)
- `--ut-atr-coef` UTBot ATR coefficient (default: 2.0)
- `--ut-atr-len` UTBot ATR period (default: 1)
- `--confirm-window` allow confirmation across N bars (0=same bar)
- `--dry-run` do not write CSV; print summary only

### Output
Appends to `outputs/entries.csv` with columns: entry_id, timestamp, symbol, timeframe, side, entry_price, tp, sl, atr, st_trend, ut_signal, st_up, st_down, pivot_low, pivot_high, tp_source, sl_source, comment.

### Notes
- TP/SL are chosen from nearest confluence levels produced by `FibonacciSquareOfNine.analyze_market()`; if none, the bot falls back to pivot_high/pivot_low.
- Deduplication is by a deterministic `entry_id` hash built from timestamp|symbol|timeframe|side|entry_price. Existing entries are not re-added.
- This script runs offline from the saved bars CSV. To keep bars up to date, use `mt5_bg_collector.py`.

## Live MT5 Bot
Places live orders on MetaTrader 5 when SuperTrend and UTBot align on the latest bar; TP/SL derived from S9 confluences with ATR/pivot fallbacks. Requires MetaTrader5 Python package and a configured terminal (see `config.py`).

### Run once (dry-run)
```powershell
python live_entry_bot_mt5.py --once --dry-run --symbol XAUUSD --timeframe H1 --confirm-window 12
```

### Start loop (every 60s)
```powershell
python live_entry_bot_mt5.py --timeframe H1 --confirm-window 12 --risk-pct 1.0 --dry-run
```
Remove `--dry-run` to place real orders after validating behavior.

### Key flags
- `--symbol` (default XAUUSD)
- `--timeframe` (M1/M5/M15/M30/H1/H4/D1)
- `--confirm-window` bars to allow alignment across (0=same bar)
- `--risk-pct` percent of balance risked per trade for position sizing
- `--allow-multiple` permit multiple concurrent positions for the symbol
- `--once` run just once and exit
- `--interval` seconds between polls in loop

### Safety
- Starts in `--dry-run` mode; review `outputs/orders.csv` before going live.
- Uses a simple risk-based lot calculation from SL distance and symbol tick value/size; verify with your broker specs.
- Ensures SL/TP are placed on the correct side of entry; rounds to the symbol tick grid.

## Harmonic Signals (new)

This workspace includes a harmonic signal generator based on the `ancient-science-of-numbers` library
and the design specified in `harmonic_trading.md`.

Quick example (live MT5):

```powershell
python scripts/run_harmonic.py --symbol XAUUSD --timeframe H1 --harmonics 1800,1850
```

You can enable background harmonic analysis in `mt5_bg_collector.py` by setting `HARMONIC_SIGNALS_ENABLED = True`
in `config.py`. When enabled the collector will persist signals to `outputs/harmonic_signals.jsonl` and —
optionally — send them to your Telegram group when `HARMONIC_SIGNALS_TELEGRAM = True` and `TELEGRAM_GROUP_ID` is set.
