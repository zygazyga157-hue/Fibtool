# Fibtool Documentation

This folder contains usage guides and technical notes for the scripts in the repository that run from the terminal.

Docs included:

- `entry_bot.md` — Offline entry detector using SuperTrend + UTBot and S9 TP/SL derivation
- `live_entry_bot_mt5.md` — Live MT5 trading bot (places orders via MetaTrader5)
- `mt5_bg_collector.md` — Background collector for bars, analysis and confluences
- `launcher.md` — Orchestrator for multi-symbol / multi-timeframe live bots
- `live_trade_setup_bot_mt5.md` — Per-symbol live trade execution helper (MT5)

Each doc includes: purpose, CLI usage (PowerShell examples), configuration, technical notes, outputs produced, best-run strategies, and common edge cases.
