
ASIA SWEEP LONDON MSS - DATASET & FEATURE PIPELINE NOTES
========================================================

FILE 1: prepare_dataset.py
--------------------------
Purpose:
- Replays TRUE M5 bars.
- Generates one row per qualified Asia Sweep -> MSS confirmation.
- Labels trades based on TP before SL before London session end.
- Uses worst-case execution logic (SL wins ties).
- Supports both long and short confirmations.

Key Components:
- load_m5_bars()
- load_m15_bars()
- compute_atr14()
- compute_mss_flags()
- compute_asia_range()
- find_sweep_events()
- choose_confirmation()
- choose_all_confirmations()
- simulate_label()
- build_dataset_for_symbol()

Dataset Output:
- t0
- symbol
- label
- FEATURE_COLS
- debug fields:
    side
    entry
    stop
    tp
    sweep_time
    fill_time

Training Run Results
--------------------

Run 1 (SMOTE + Residual):
- Dataset rows: 384
- Best Validation AUC: 0.7544
- Test AUC: 0.5510
- Test Accuracy: 0.7414
- Precision: 0.2500
- Recall: 0.3333
- F1: 0.2857

Run 2 (No SMOTE, No Residual):
- Best Validation AUC: 1.0000
- Test AUC: 0.5669
- Test Accuracy: 0.8276
- Precision: 0.3333
- Recall: 0.1111
- F1: 0.1667

Observations:
- Validation performance is much higher than test performance.
- Dataset size remains very small (384 samples).
- Evidence of overfitting.
- More history and more symbols are likely needed.

Hard Candlestick Block:
-----------------------
evaluate_candlestick_hard_block()

Rules:
1. Reject contradictory candle signals.
2. Reject weak aligned signals below minimum score.
3. Optionally reject neutral signals.
4. Pass only aligned and sufficiently strong candle confirmations.
